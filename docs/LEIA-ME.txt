LINCE — pacote integrado para GitHub Pages.
Inclui dashboard, lançamentos, cartões, contas previstas/recorrentes, importação CSV/OFX/PDF digital/XLSX (PDF.js e SheetJS carregados sob demanda), backup JSON, PWA.
Limitações: leitura PDF heurística e exige PDF com texto selecionável; não há OCR de PDF escaneado, Open Finance, sincronização, criptografia ou conciliação bancária automática. Dados locais no navegador. Fazer backup regularmente.
